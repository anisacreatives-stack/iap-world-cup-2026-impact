# It's a Penalty · FIFA World Cup 2026 Impact Report

An animated, scroll-driven web version of It's a Penalty's North America impact report.
Static site (HTML/CSS/JS, no build step). Deployed on Vercel.

- `index.html` – page structure and copy
- `cities.js` – host-city data (edit numbers and text here)
- `main.js` – scroll animations, count-ups, city sections
- `styles.css` – design
- `img/` – photos extracted from the report PDF
